# Henry's Space｜林恩睿個人介紹網站

政治大學廣告系大三 林恩睿（Henry）的個人介紹網頁。

## 如何開啟

直接雙擊 `index.html`，即可在瀏覽器預覽。這是純 HTML + CSS 靜態網站，不需要安裝軟體或執行程式。

## 如何發布到 GitHub Pages

1. 在 GitHub 新增 **Public** repository，例如 `henry-personal-site`。
2. 進入 Repository → **Add file** → **Upload files**。
3. 上傳 `index.html`、`style.css`、`assets` 資料夾（及 README.md），不要只上傳 ZIP 檔。
4. 點選 **Commit changes**。
5. 進入 **Settings** → **Pages** → **Build and deployment**。
6. **Source** 選 `Deploy from a branch`，**Branch** 選 `main`，資料夾選 `/(root)`，點 **Save**。
7. 發布完成後，個人網頁網址通常是 `https://你的GitHub帳號.github.io/henry-personal-site/`。

## 修改內容

- 個人資料、介紹：修改 `index.html`。
- 配色、字型、版面：修改 `style.css`。
- 內建圖標：`assets/favicon.svg`。

## 名片 QR Code

網站上線後才產生真正的 QR Code，並以手機掃描確認能開啟 GitHub Pages 網站。先前的名片設計圖上的 QR Code 是示意圖，並非可用的網址 QR Code。
